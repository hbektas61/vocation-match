# Vocation Match Studio State

This folder is the durable coordination layer for Claude Studio.

- `brief.md`: product scope and constraints.
- `decisions.md`: product truths that agents must not silently override.
- `agent-plan.md`: current milestone, agents, gates, and completion promise.
- `backlog.md`: ordered work.
- `handoffs.md`: agent-to-agent context.
- `metrics.md`: product and quality measurements.
- `release-checklist.md`: release gates.
- `loop-prompt.md`: bounded autonomous Studio/Ralph loop.
